## 一、项目背景

在零售行业竞争日趋激烈的背景下,超市运营已从"经验驱动"逐步转向"数据驱动"。然而,大多数超市仍存在以下运营痛点:

| 痛点 | 现状 | 影响 |
|---|---|---|
| **陈列盲调** | 商品摆放依赖店长经验,无量化依据 | 坪效低,畅销品未获最佳位置 |
| **客流分布未知** | 不知道哪些区域拥挤、哪些冷清 | 资源错配,顾客体验差 |
| **活动效果难量化** | 促销投入与产出无对应关系 | 营销预算浪费 |
| **高峰期响应慢** | 收银台、试衣间排队无预警 | 顾客流失 |
| **数据资产缺失** | 无长期客流数据沉淀 | 决策缺支撑 |

**本方案**旨在通过现有安防摄像头网络,以最小改造成本,为超市提供一套**实时、精准、可视化**的客流与停留分析系统。

---

## 二、建设目标

1. **实时可视化**:在超市平面图上动态展示各区域人流密度与停留时长
2. **数据驱动决策**:为陈列调整、人员调度、营销活动提供数据依据
3. **轻量部署**:复用现有摄像头,不打断日常运营
4. **长期可用**:7×24 小时稳定运行,持续积累运营数据

## 三、解决方案概述

### 3.1 核心思路

采用 **"现有摄像头 + 边缘 AI 智能分析 + 中心可视化平台"** 的轻量化三层架构:

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  摄像头层    │ → │  智能分析层  │ → │  可视化层    │
│  (前端感知)  │   │  (中台计算)  │   │  (后端呈现)  │
└──────────────┘   └──────────────┘   └──────────────┘
  现有安防摄像头     GPU 服务器/边缘盒       Web 大屏
                                       PC/手机/平板
```

- **摄像头层**:复用现有安防摄像头,无需更换硬件
- **智能分析层**:在后台 GPU 服务器或边缘计算盒上完成 AI 分析,自动识别人体位置与停留时长
- **可视化层**:通过 Web 平台呈现红蓝热力图,支持大屏、PC、手机多端查看

### 3.3 数据流向(5 步闭环)

| 步骤 | 动作 | 说明 |
|---|---|---|
| ① 视频采集 | 摄像头持续推送 RTSP 视频流 | 复用现有网络,无需新增布线 |
| ② 行人识别 | AI 引擎逐帧检测画面中的行人,并持续跟踪每个人的轨迹 | 单相机内独立跟踪,准确率 >95% |
| ③ 位置映射 | 将识别到的行人位置,通过预先标定的对应关系,映射到超市平面图坐标系 | 精度 30-50 cm,符合运营分析需求 |
| ④ 停留累积 | 在平面图网格中实时累加每个人的停留时长,带时间衰减 | 自动丢弃历史数据,反映"近期"热度 |
| ⑤ 可视化呈现 | 通过浏览器/WebSocket 实时推送到大屏,叠加在平面图上 | 1 秒级延迟,红蓝热力图直观展示 |

### 3.4 多摄像头协同

超市通常面积较大,**单一摄像头视角有限**,必须由多台相机协同覆盖。本方案采用:

- **每个相机独立标定**:在地面设置 4 个标记点,自动建立"相机画面 ↔ 平面图"的对应关系
- **重叠区加权融合**:多相机共同覆盖的区域自动平滑过渡,无拼接裂缝

### 3.5 无缝拼接技术原理

多相机协同的最大工程挑战,在于**消除拼接处的视觉裂缝**。本方案通过"可信度地图 + 加权融合"机制,从原理上彻底解决这个问题。

#### 为什么会有"拼接裂缝"

每台相机都有自己的视野范围,如同手电筒照射的光锥。在视野中心,识别精度最高;在视野边缘,识别精度会下降。如果直接把所有相机的热力图拼在一起,在两个相机的交界处就会出现明显的"硬边"。

#### 解决方案(三步)

```
┌─────────────────────────────────────────────────────────────┐
│  ① 标定阶段                                                 │
│     每台相机独立建立"画面 ↔ 平面图"的对应关系                │
│     同时生成该相机在地面上的"可信度地图"                      │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  ② 运行阶段                                                 │
│     每台相机独立生成热力图(只在自己的可信区域内累加)           │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  ③ 融合阶段                                                 │
│     最终热力图 = Σ(各相机热力 × 可信度) ÷ Σ可信度             │
│     重叠区按可信度自动加权,边界自然过渡                       │
└─────────────────────────────────────────────────────────────┘
```

#### 可信度地图的形态

为每台相机生成一张"可信度地图",类似相机视野在地面上的光斑:

```
        相机A的可信度        相机B的可信度        融合后
       ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
       │░░▓▓████▓▓░░ │     │ ░░▓▓████▓▓░░│     │▓▓████████▓▓│
       │░▓███████▓░  │     │  ░▓███████▓░│     │▓██████████▓│
       │░▓███████▓░  │  +  │  ░▓███████▓░│  =  │█████████████│
       │░░▓▓████▓▓░░ │     │ ░░▓▓████▓▓░░│     │▓▓████████▓▓│
       └─────────────┘     └─────────────┘     └─────────────┘
       (深=高可信,浅=低可信)                  (平滑无硬边)
```

- **相机正下方 / 正前方**:可信度最高(深色,识别精度最高)
- **视野边缘**:可信度逐渐降低(浅色,识别精度下降)
- **视野外**:可信度为零(不参与融合)

#### 融合后的优势

| 区域类型 | 视觉效果 | 数据特点 |
|---|---|---|
| 单相机覆盖区 | 单一结果,清晰准确 | 来自该相机的热力值 |
| 双相机重叠区 | 颜色自然过渡,无硬边 | 两侧相机的加权平均,精度更高 |
| 多相机核心区 | 颜色平滑融合 | 多源数据印证,可靠性最高 |
| 极少数盲区 | 留空(冷色) | 不强行填值,避免误导 |

#### 客户视角的额外价值

- **无需手动拼接**:系统自动完成,部署即用
- **标定简单**:每台相机只需 4 个地面标记点,10 分钟即可完成
- **相机微调不破坏系统**:位置小幅调整后,只需重新标定该相机,不影响其他相机
- **支持相机扩容**:新增相机时,只需标定新相机并入系统,自动与现有相机融合

## 四、核心功能

### 4.1 实时热力图(主功能)

- 在超市平面图上,实时显示各区域的客流密度
- **红色** = 停留人数多 + 停留时间长 = 热门区域
- **蓝色** = 停留人数少 + 停留时间短 = 冷清区域
- 支持切换:实时热力图 / 当日累计 / 时段对比
- 1 秒级刷新,支持大屏投放

### 4.2 区域停留分析

- 自动识别**高关注低转化**区域(顾客长时间停留但购买率低)
- 自动识别**高流转区域**(顾客快速经过,可能是动线问题)
- 为商品陈列调整提供量化依据


### 4.4 历史数据回溯

- 支持查询任意历史时段的热力图分布
- 支持按日 / 周 / 月生成趋势报告
- 数据长期保存,可作为运营决策的历史依据

### 4.5 多店统一管理(连锁超市)

- 总部可统一查看所有门店实时画面
- 支持分店 / 区域 / 时段多维度对比
- 一套平台,管理全国门店

## 五、技术亮点

### 5.1 极简部署

- **复用现有摄像头**:不强制更换硬件,降低前期投入
- **接入方式灵活**:支持 RTSP、ONVIF 等主流协议

- **不保存视频**:原始视频仅用于实时分析,不写入磁盘
- **符合《个人信息保护法》要求**:无个人身份信息留存

### 5.3 精度可控

| 指标 | 数值 | 说明 |
|---|---|---|
| 行人检测准确率 | ≥95% | 主流深度学习模型 |

| 系统延迟 | <2 秒 | 从行为发生到前端显示 |
| 单相机覆盖范围 | 8-15 m 半径 | 取决于相机高度和角度 |

### 5.4 高可用设计

- **断网自恢复**:网络中断后自动重连,数据不丢失
- **异常告警**:设备离线、相机遮挡等异常自动通知运维人员

## 十、常见问题 FAQ

**Q1:必须更换现有摄像头吗?**  
A:不必。系统兼容主流安防摄像头,只要支持 RTSP/ONVIF 协议即可直接接入。

**Q2:对网络带宽有什么要求?**  
A:单路摄像头约需 2-4 Mbps 上行带宽。普通百兆局域网即可承载 10 路相机。

**Q3:需要专门的 GPU 服务器吗?**  
A:典型部署(8 路以内)只需 1 台中等配置 GPU 工作站即可。如果已有其他业务服务器,可考虑边缘计算盒方案。

**Q4:分析数据是否涉及隐私?**  
A:不涉及。系统仅分析人体位置和停留时长,不提取人脸、不存储原始视频,符合《个人信息保护法》。

**Q5:数据是否安全?**  
A:全部数据存储在客户本地服务器,不上传至第三方。可根据需求部署在内网或专网环境。

**Q6:能否支持多店连锁?**  
A:支持。一套平台可同时管理数十家门店,总部统一查看,分店独立运营。

**Q7:后续维护复杂吗?**  
A:简单。系统具备自恢复能力,日常无需专人值守;我们提供远程技术支持 + 定期巡检。

**Q8:能否试用?**  
A:支持。我们可在客户选定门店先做试点验证(1-2 周),用真实数据验证效果后再全面推广。
